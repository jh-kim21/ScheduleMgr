보안 관점에서만 코드를 검토합니다. 다음 항목을 중심으로 확인하세요:

- 인증/인가 로직의 우회 가능성
- 입력 검증 누락 (SQL 인젝션, XSS, 커맨드 인젝션 등)
- 토큰/세션/쿠키 처리의 안전성
- 하드코딩된 시크릿, API 키, 자격 증명
- 의존성 취약점, 안전하지 않은 역직렬화

발견한 이슈는 파일 경로와 라인 번호, 재현 가능한 시나리오, 심각도(critical/high/medium/low)를 포함해 보고하세요. 성능이나 코드 스타일 문제는 다루지 않습니다.
